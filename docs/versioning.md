# Версии и совместимость ядра (CR-23)

Ядро `stoat-crypto` и его привязки (AAR и npm-пакет `@durio/stoat-crypto`) имеют **одну** версию — версию
крейтов workspace (`Cargo.toml`, `[workspace.package]`; `bindings/web/package.json` сверяется сборкой). Тег `vX.Y.Z`
в `durio-crypt` выпускает AAR и tarball npm-пакета той же версии (`aar.yml`, `wasm.yml`).

## Semver

Пока E2EE — «бета» (O8), версия `0.x`:

| Что изменилось | Версия | Пример |
| --- | --- | --- |
| Публичный API ядра или поверхность FFI/wasm (новая функция, поле записи, вариант ошибки или enum) | `0.MINOR` | 0.1 → 0.2: экспорт/импорт ключей, `debug_report` |
| Поведение без изменения API, исправления | `0.x.PATCH` | исправление щита, нового хранилища нет |
| Обновление `matrix-sdk-crypto` (схема хранилища библиотеки может мигрировать) | `0.MINOR` | 0.19 → 0.20 |

Kotlin/JS-код клиента видит смену MINOR как ломающую (новый вариант `sealed`-исключения ломает
исчерпывающий `when`), поэтому пин AAR в Android (SHA-256) меняется вместе с кодом клиента. `1.0.0` — после
закрытия чек-листа ревью (`docs/review-checklist.md`) и прогона T1–T19 на стенде; дальше — обычный semver.

## Хранилище: только вперёд

- Схему SQLite/IndexedDB мигрирует библиотека при открытии (`store_016_migrates_to_019`). Наши значения в
  `custom_value` — ключи с версией (`stoat.seen.v1`, `stoat.backup.v1`, …). Новый формат значения — **новый
  ключ** (`.v2`) и чтение старого при открытии; старый ключ читается, пока жив хотя бы один снимок с ним.
- **Тест «N−1 открывается в N»**: `fixtures/stores/v010/` — хранилище, записанное 0.1.0 (аккаунт, входящие и
  свои сессии Megolm, таблицы CR-19, состав канала, обработанные-но-не-подтверждённые id ящика C2, состояние
  бэкапа и ключ секретного хранилища). `tests/compat.rs::store_v010_opens_in_current_version` проверяет всё это
  в текущей версии. Снимок заморожен: перезаписывать (`DUMP_STORE_V010=1`) нельзя; каждый выпуск, меняющий
  хранилище или версию библиотеки, **добавляет** свой снимок (`fixtures/stores/v<версия>/`) и тест к нему.
  В снимках — только тестовые ключи фейкового сервера, ключ хранилища — 32 байта `0x42`.
- **Откат версии не поддерживается**: N−1 может не открыть хранилище после миграции N. Откат приложения =
  `destroy` + восстановление из бэкапа или файла экспорта (CR-21).

## Конверт v1: строгий

`{v, algorithm, session_id, device_id, ciphertext}` с `deny_unknown_fields` (CR-03). Новое поле или иная
семантика — только `v: 2`; N−1 показывает такое сообщение как «обновите приложение»
(`DecryptError::UnsupportedVersion` / `UnknownAlgorithm` → `DecryptFailureKind::UpdateApp`). Бэкенд хранит
конверт как есть.

## Payload v1: только расширение

- Неизвестные поля **игнорируются** на любом уровне (payload, вложение, `EncryptedFile`) — без
  `deny_unknown_fields`. Тест `payload_with_unknown_fields_decrypts`: сообщение «новой версии» с лишними полями
  читается, известные поля на месте.
- Новое поле — только необязательное, со значением по умолчанию, и его отсутствие означает прежнее поведение.
  Поле, без понимания которого сообщение покажется **неверно** (а не просто беднее), — это `v: 2`; N−1
  отвечает `UnsupportedVersion` (тот же тест).
- Оговорка: старый клиент, правящий сообщение нового, отправит правку без незнакомых ему полей.
- Паддинг (`pad`) считается по всему объекту, включая незнакомые поля (`payload::pad_value`).

## JSON `/e2ee/*`

Форма Matrix CS API v1.x (C1), меняется только добавлением полей; бэкенд и ядро игнорируют незнакомые поля
ответов. Контракт — `fixtures/api/` (хеши в `SHA256SUMS`, копия в бэкенде).

## Обновление библиотеки

Пины `=x.y.z` (ADR 0001), раз в квартал отдельным PR: зелёные сценарии, табличные тесты адаптера и **все**
снимки хранилищ; версия ядра — следующая MINOR.

## Открыто

- Матрица версий «Android × веб» в CI стенда (CR-15): привязки wasm есть (CR-14, 0.2.0), прогон двух клиентов
  на стенде — с WEB-08.
- Снимок хранилища IndexedDB («N−1 открывается в N» для веба): в Node нет IndexedDB, нужен headless Chrome в CI
  (CR-14 отложил); до него веб полагается на миграции библиотеки и на тот же формат `custom_value`, что SQLite.
